## 2026-09-27 补充核对

本轮以**本机安装的 DSH 0.1.5-rc.1**（`~/.local/lib/node_modules/@deepseek-ai/dsh`）
的产物为准逐项核对，不再只依赖上游文档：

| 核对项 | 本机依据 |
| --- | --- |
| `session/create` 的线格式 | `dsh-api-session-controller/lib/typert.host.js` 生成的 invocation 描述符 |
| `SessionCreateRequest` 字段 | `dsh-api-session-controller/lib/types/types.d.ts` |
| RPC 信封与错误形状 | `dsh-client-connection/lib/types/rpc.d.ts` |
| 404 与业务失败的区分 | `dsh-client-connection/lib/index.js` 的 `createSharedFetchHandler` |
| 导出端点的方法与参数校验 | `dsh-session-log-export/lib/index.js` |
| 预设 API 只有五个方法 | `dsh-agent-presets/lib/typert.remote-client.d.ts` |
| `blank` 字段语义 | `dsh-api-session-controller/lib/types/types.d.ts`（"Whether the folded prefix contains no turn"） |
| 会话无删除端点 | 同上文件的 Remote 映射表中确无 delete |
| 宿主注入插件不属于预设 | `mcp__computer_use__*` / `node_repl` 不在 DSH 的 `node_modules/@deepseek-ai/` 内 |

DSH 属开发预览，接口仍可能变化；升级后建议先用 `docs/协议与版本.md` 里的对照表
重新核一遍本机描述符，再运行测试。

## 关于「问模型你有哪些工具」

不建议用这种方式判断预设能力。会话导出里的 `request/header` 事件
（`data.header.tools`）才是 DSH 发给模型的权威清单。实测同一预设在自述中
得到过 13 / 2 / 0 三种结果，格式漂移足以让任何基于它的断言失效。
