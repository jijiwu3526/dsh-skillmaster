# 规划会话第一条消息

我希望做一个专供工作使用的 DSH Agent Preset。请先只做需求访谈，不改配置、不创建正式会话。每轮最多问 3 个最关键问题，记录我已确认的结论，直到足以写出下面的规格：

1. 工作目标、典型输入、理想输出、成功判据与不做的事。
2. 实际工作区路径、常用文件类型、可用工具、外部服务和需要人工确认的操作。
3. 回复语言、格式、风格、引用或证据标准、文件命名与保存位置。
4. 开始新会话时需要带入的持久知识，以及不该从访谈会话继承的临时上下文。
5. 至少 3 个真实任务样例与预期结果、2 个边界或失败样例。

我说“确认规格”后，请输出：

- 一份按 `02-工作用途与预设规格.md` 所列标题组织的完整 Markdown；未知项写“待确认”，不要编造。

- 一份可供 Creator 实施的功能清单和验收步骤。
- 一份对话摘要：已确认事实、仍有争议的决定、取舍理由、后续行动。

在我明确确认前，不要把猜测写成最终规则。
